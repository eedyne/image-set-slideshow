# 묶음 이미지 슬라이드

이미지의 확장자가 달라도 파일명의 `이름 (번호)` 부분을 기준으로 자동 묶음 처리하는 Windows용 슬라이드 프로그램입니다.

예를 들어 아래 세 파일은 하나의 `fh23g1` 묶음으로 인식하며, 반드시 1 → 2 → 3 순서로 재생합니다.

```text
fh23g1 (1).png
fh23g1 (2).jpg
fh23g1 (3).png
```

## 동작 규칙

- 한 묶음은 3~5장이어야 합니다.
- 각 묶음의 번호는 `(1)`부터 빠짐없이 이어져야 합니다.
- PNG, JPG, JPEG, WEBP, BMP, GIF, TIF, TIFF를 함께 넣어도 됩니다.
- 묶음 내부 이미지는 번호순으로 재생합니다.
- 묶음 순서만 무작위로 섞습니다.
- 한 사이클 안에서는 같은 묶음이 중복되지 않습니다.
- 모든 묶음이 끝나면 새로운 순서로 다시 섞습니다.
- 사이클 경계에서도 같은 묶음이 연속되지 않게 처리합니다.
- 이미지 사이 또는 묶음 사이에 대기 화면이 없습니다.
- 원본 비율을 유지하며 화면 안에 맞춥니다.
- 큰 이미지는 현재 화면 크기로 축소해 소량만 임시 보관하므로, 파일이 많아도 전체를 메모리에 올리지 않습니다.

## 실행 방법

1. Windows에 Python 3.11 이상이 없다면 [Python 공식 사이트](https://www.python.org/downloads/)에서 설치합니다. 설치 화면에서 `Add Python to PATH`를 선택하세요.
2. `install.bat`을 한 번 실행합니다.
3. 이후에는 `run.bat`을 실행합니다.
4. 프로그램의 **이미지 폴더 열기**를 누르고 이미지가 들어 있는 폴더를 선택합니다.

## 키보드 조작

| 키 | 기능 |
|---|---|
| `Space` | 일시정지 / 다시 재생 |
| `→` | 다음 이미지 |
| `←` | 이전 이미지 |
| `F11` | 전체화면 켜기 / 끄기 |
| `Esc` | 전체화면 종료 |
| `Ctrl + O` | 이미지 폴더 열기 |

상단의 **장당 초** 값을 바꾸고 Enter를 누르면 재생 중에도 새 시간이 바로 적용됩니다. 0.1초부터 3600초까지 지정할 수 있습니다.

## EXE 파일 만들기

Python 없이 실행할 수 있는 단일 EXE가 필요하면 `build_exe.bat`을 실행하세요. 제작이 끝나면 `dist\ImageSetSlideshow.exe`가 생성됩니다. 이미지들은 EXE 안에 넣지 않고, 실행 후 폴더를 선택해서 사용합니다.

## 파일명이 잘못된 경우

아래와 같은 파일은 자동으로 제외되고 안내창에 이유가 표시됩니다.

- 괄호 번호가 없는 파일: `fh23g1.png`
- 묶음 이미지가 2장 이하 또는 6장 이상인 경우
- 번호가 빠진 경우: `(1), (2), (4)`
- 같은 묶음 안에서 번호가 중복된 경우: `(1).jpg`와 `(1).png`
